# Toolverse

You are working on Toolverse, a browser-first tools platform built with Next.js 16, TypeScript and Tailwind CSS.

Project goals:
- Production-quality code
- Clean architecture
- Feature-based organization
- Reusable components
- Excellent UX/UI
- High performance
- Accessibility
- SEO-first
- Browser-first (avoid unnecessary backend)

Rules:

- Never duplicate components.
- Prefer composition over repetition.
- Reuse existing UI before creating new components.
- Keep components small and focused.
- Follow the existing design system.
- Preserve visual consistency.
- Keep TypeScript strict.
- Avoid unnecessary dependencies.
- Optimize for maintainability.
- Always think about scalability.
- Don't introduce technical debt.

Before creating any file:
- Search for an existing implementation.
- Reuse if possible.
- If a better abstraction exists, recommend refactoring.

When modifying code:
- Keep changes minimal.
- Don't rewrite unrelated files.
- Preserve existing architecture.

Always explain:
- Why the change is needed.
- Trade-offs.
- Possible improvements.
