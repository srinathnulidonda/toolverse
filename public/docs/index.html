Overview

What is Toolverse?

A fast, privacy-first utility hub that handles every digital task a user touches daily — compressing a PDF for email, resizing a photo for Instagram, generating a QR code, building a resume, or formatting a JSON blob.

Everyone lands on bloated, slow, ad-heavy sites that force sign-ups and impose file limits. Toolverse is faster, cleaner, and free.

Zero friction
No sign-up, no email, no credit card — ever
Privacy first
Files processed in your browser, never uploaded
Mobile first
Every tool works on a phone
Global + regional
GST, VAT, and region-specific tools built in
Speed
Results in under 3 seconds — no server round-trips
Ad-only revenue
One AdSense slot per page, no subscriptions

Database

Database schema

-- Users
CREATE TABLE users (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  clerk_id   TEXT UNIQUE NOT NULL,
  email      TEXT UNIQUE,
  plan       TEXT NOT NULL DEFAULT 'free',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Subscriptions (future-proofing)
CREATE TABLE subscriptions (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id       UUID REFERENCES users(id) ON DELETE CASCADE,
  stripe_sub_id TEXT UNIQUE,
  plan          TEXT NOT NULL,
  status        TEXT NOT NULL,   -- 'active' | 'cancelled' | 'expired'
  starts_at     TIMESTAMPTZ NOT NULL,
  ends_at       TIMESTAMPTZ NOT NULL
);

-- Tool analytics (zero PII)
CREATE TABLE tool_events (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tool         TEXT NOT NULL,
  action       TEXT NOT NULL,   -- 'upload' | 'process' | 'download' | 'error'
  file_size_kb INT,
  result_kb    INT,
  duration_ms  INT,
  created_at   TIMESTAMPTZ DEFAULT NOW()
);

-- Row Level Security
ALTER TABLE users ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users read own data" ON users FOR SELECT
  USING (clerk_id = auth.uid()::text);

ALTER TABLE tool_events ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Anyone can insert" ON tool_events
  FOR INSERT WITH CHECK (true);
API

API design

Internal (Next.js serverless)

POST  /api/convert
      Body: { file: base64, from: 'pdf', to: 'docx' }
      Rate: 10 req/hr
      → Proxies to Railway LibreOffice

POST  /api/analytics/event
      Body: { tool, action, file_size_kb, result_kb, duration_ms }
      Auth: None · zero PII collected

GET   /api/user/plan
      Auth: Clerk session
      → { plan, limits }

External developer API (Month 6+)

Base: https://api.toolverse.com/v1
Auth: Bearer {API_KEY}

POST /v1/pdf/compress
POST /v1/pdf/merge
POST /v1/image/compress
POST /v1/image/resize

200: { success: true, file: base64, original_kb, result_kb }
429: { error: "Rate limit exceeded" }
402: { error: "Upgrade required" }
